# Linktree USF - Andaia

Página responsiva de acessos rápidos da USF Andaia. A interface usa React e menus flutuantes com rolagem interna para reunir serviços, documentos, contatos e links institucionais.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run check
npm run build
```

Os conteúdos e URLs ficam na constante `categories` em `src/App.tsx`.
